# AI-enabled-Java-Full-Stack-Developer-Cognizant-Training

This repository comprises my notes, exercises, and assignments completed during my training under Revature.

## Notes

I made a shell script called ungit_commit.sh which renames nested .git folders to an ignored name before staging and committing them because I don't want to bother making them submodules and I'd rather git not yell at me every time it saw them. This does mean things like their commit history isn't included in the repo, however. For small tests and labs, I think this is fine. 

More substantial repos will be made into submodules so their full history can be seen.
