This repository comprises my notes, exercises, assignments, and projects completed during my training under Revature.

## Nested Git Repositories

During training, there are projects and other assignments which I created git repos for. As far as I'm currently aware, there's no easy, non-submodule way for a nested repo to exist and still work as normal. Thus, most of the less-important repos, like the ones made for exercise, simply won't be accessible (until I've learned a way to merge their history into a subfolder--not overwriting the root's files). Project and assignment repos will be made into submodules so their files and commit history are visible.

### P.S

I did make an ungit_commit.sh script which renames all inner .git folders to an ignored name before committing them so that at least these repos' files could be viewed. However, it makes staging and committing take much longer. As previously stated, any inner repo that isn't a submodule doesn't contain any important files--assignments, projects, notes, etc. --so I won't be using that script anymore.
