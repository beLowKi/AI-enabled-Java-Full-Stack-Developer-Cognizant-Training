## Business scenario

You have joined the development team at TechNova Solutions. The team is building an Employee Management System for the HR department. The source code is maintained in GitHub, and developers use branches, commits, pushes, pulls, and pull requests to collaborate.

Your team follows these practices:

- `main` contains stable code.
- Developers create feature branches for new work.
- Meaningful changes must be committed.
- Feature branches must be pushed to GitHub.
- Completed work is integrated into `main` after review.
- Developers must synchronize their local repository with remote changes.
