
| Name          | Method                                                                                                                 | Complexity                  |
| ------------- | ---------------------------------------------------------------------------------------------------------------------- | --------------------------- |
| Brute force   | Search every item individually                                                                                         | O(n)                        |
| Linear search | Start from start/end and search to other end                                                                           | O(n)                        |
| Binary search | Sort structure, check middle, based on comparison you move to left (<) or right (>=) half until you've found the value | O(log\*(n))<br><br>\*base 2 |
