
A major component of [[Data Structures]] is their search efficiency. Often discussed in terms of:

| Case         |                                                 | Notation |
| ------------ | ----------------------------------------------- | -------- |
| Best Case    | Target is found on first iteration              |          |
| Average Case | Average number of iterations a search will take |          |
| Worst Case   | Target is found on last possible iteration      |          |

These are usually expressed in mathematical terms--scaling with the size (number of values) of the structure.
