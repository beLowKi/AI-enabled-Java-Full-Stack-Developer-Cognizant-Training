
DSs are a way for programs to organize and store data efficiently. They also help programmers define logical groups of data: Employee, Product, Customer, etc.

- Linear -> Elements sit in a sequence; i.e., there's an order to the data
- Non-linear -> Data is unordered across levels or links

Arrays use continuous memory (allocated blocks are next to each other). By comparison, Linked lists allow their items to be split across various memory locations.

## Key Purposes

1. Organize memory
2. Optimize for business requirement
3. Optimize inserts, reads, and deletes
